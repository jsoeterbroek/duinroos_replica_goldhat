# catalogues

The reference catalogues used for novelty checks, and for each: how it was checked
(full read vs search-inside) and what was found.

| Catalogue | Checked | Purpose |
|---|---|---|
| `menghin_numbers.md` | full read + scripts | has this number already been measured? |
| `fuls.md` | full read (page images) | has this statistical claim already been made? |
| `wikipedia_and_museum.md` | search-inside | stop re-importing secondary claims |

**Rule (from `../AGENTS.md`):** record *how* each catalogue was checked. A
search-inside is not a full read; say which was done and note when search-inside is
unreliable (e.g. for a bibliography's completeness).
