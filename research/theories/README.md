`../CASE.md`.

## How to use this folder

- A theory file is an **argument to be attacked**, not evidence. The evidence
  lives in `../sources/`, `../evidence/`, `../findings/` and the `scripts/`.
- The two legacy assessments (`menghin_lunisolar.md`, `schmidt_kaler_venus.md`)
  are the most detailed and carry their own Monte-Carlo and subset tests; start
  there for the numbers.
- The sceptical file is not a "none" theory: it is the current best reading and it
  sets the bar any positive claim must clear.
